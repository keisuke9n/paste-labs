# Paste Labs

Paste → Verify → Analyze

A collection of local-first clinical analysis tools.

## Applications

- eGFR Slope Analyzer
- LDL Response Analyzer (planned)
- HbA1c Trend Analyzer (planned)
- BNP Trend Analyzer (planned)

## Principles

- Local-first
- Open source
- No cloud processing
- User verification required
- No AI-based clinical decision making
